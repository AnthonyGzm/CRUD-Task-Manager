# CRUD Task Manager

Aplicación web para la gestión de tareas desarrollada con **PHP, MySQL, Apache y Bootstrap 5**, implementando un CRUD completo.

---

## 📌 Descripción

Este proyecto permite administrar tareas de forma sencilla, incluyendo la creación, visualización, edición y eliminación de registros. 


---

## 🛠️ Tecnologías utilizadas

*   **Lenguaje:** PHP
*   **Base de Datos:** MySQL
*   **Servidor:** Apache (XAMPP)
*   **Frontend:** Bootstrap 5 & CSS3

---

## ⚙️ Funcionalidades

- **Crear tareas:** Registro de nuevas actividades.
- **Listar tareas:** Visualización dinámica de la base de datos.
- **Editar tareas:** Actualización de registros existentes.
- **Eliminar tareas:** Borrado lógico o físico de datos.
- **Validación:** Control de formularios para evitar campos vacíos.
- **Diseño Responsivo:** Interfaz adaptable a dispositivos móviles.

---

## 🚀 Instalación y ejecución

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/AnthonyGzm/CRUD-Task-Manager.git
    ```

2.  **Mover el proyecto:**
    Copia la carpeta a la ruta de tu servidor local (ej. `C:/xampp/htdocs/`).

3.  **Iniciar servicios:**
    Abre el panel de **XAMPP** e inicia **Apache** y **MySQL**.

4.  **Configurar la base de datos:**
    *   Accede a [http://localhost/phpmyadmin](http://localhost/phpmyadmin).
    *   Crea una nueva base de datos.
    *   Importa o ejecuta el contenido del archivo `database.sql`.

5.  **Acceso web:**
    Ingresa en tu navegador a: [http://localhost/CRUD-Task-Manager/](http://localhost/CRUD-Task-Manager/)
